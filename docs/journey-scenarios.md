# ЕВА — Сценарии путей пользователя

Пользователь выбирает 3 сферы из 8, оценивает каждую. Сфера с наименьшей оценкой открывается первой. На входе в сферу — один уточняющий вопрос (тип проблемы), который определяет весь дальнейший путь.

---

## Шаги и их значение

| Шаг | Описание |
|---|---|
| Цель | Пользователь формулирует желаемый результат в этой сфере |
| Желаемое состояние | Пользователь называет состояние, которого хочет достичь |
| Страхи | Выбор до 3 страхов, которые мешают двигаться вперёд |
| Переосмысление страха | Разбор главного страха: что правда, что нет, какой сигнал несёт |
| Сопротивление | Оценка внутреннего сопротивления по шкале 0–10 |
| Форма сопротивления | Пользователь даёт сопротивлению форму, цвет и размер |
| EMDR | Билатеральная стимуляция — растворение телесного блока |
| Переоценка | Оценка состояния после EMDR — насколько изменилось |
| Соматика | Телесное упражнение (тряска, бабочка, стена) + замер до/после |
| Дыхание | Дыхание 4-7-8 или сканирование тела |
| Письмо себе | Два письма: из боли — и ответ от мудрой себя |
| Благодарность | 3 вещи в этой сфере, которые уже работают |
| Карта полярности | Три сценария: худший, реалистичный, лучший |
| Нарративное письмо | Свободное письмо 3 минуты, затем одно слово-итог |
| Творческое выражение | Рисунок или свободное письмо — выразить и отпустить |
| Выбор практики | Пользователь выбирает практику для закрепления результата |
| Практика | Выполнение выбранной практики |
| Итог | Финальный экран: результаты, XP, монеты, открытие следующей сферы |

---

## Отношения

| Тип проблемы | Путь |
|---|---|
| **Конфликт** | Цель → Сопротивление → Форма сопротивления → EMDR → Переоценка → Итог |
| **Дистанция** | Цель → Письмо себе → Выбор практики → Практика → Итог |
| **Хочу улучшить** | Цель → Желаемое состояние → Карта полярности → Выбор практики → Практика → Итог |
