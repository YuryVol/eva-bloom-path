  • /login email + google

  • /intro лендинг
  • /about-you имя, роли, сферы
  • /disclaimer дисклеймер
  • /welcome приветствие + видео
  • /rewards-intro гейм-механики

  • /home мир Евы, чекин, прогресс
  • Модальное: WorldStateChangedModal

3. User Flows

3.1 Онбординг (новый пользователь)

/intro → /about-you → /login → /auth-callback → /disclaimer → /welcome → 🎬 to-spheres.mp4 → /journey/spheres
Альтернатива: /auth-invite?ref=XYZ → draft → /login → восстановление draft

3.2 Полное путешествие (вариант «deep»)

/spheres → 🎬 interlude → /assess → 🎬 interlude → /path → /sphere-entry → /sphere-task → /goal → /fears → /feeling → /current-state → /resistance → /resistance-shape → /emdr-intro → 🎬 interlude → /emdr → /reassess → /practice-select → /practice-run → /success → 🎬 interlude → /summary

3.3 Ежедневный цикл

/home → чекин → /journey/spheres → путешествие → /summary → шаг в жизнь → /home
Free: 1 цикл (3 сферы) / день → DailyLimitCard → «Вернуться завтра» или «Подключить Premium»

3.4 Premium flow

Лимит / гейт → PremiumGateSheet → /premium/paywall → activatePremiumMock() → фича разблокирована
